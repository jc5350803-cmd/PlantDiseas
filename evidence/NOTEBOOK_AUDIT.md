# Notebook audit for the paper-aligned branch

## Audit rule

This audit is static. No notebook was executed. A notebook is considered evidence only when its saved outputs and execution state provide traceable support for a result already recorded for the manuscript.

| Paper section | Repository notebooks | Role |

| Primary Dataset-Specific Evaluation | `experiments/primary/NB1_Wheat_Hybrid.ipynb`; `NB2_Cotton_Hybrid.ipynb`; `NB3_PlantVillage_Hybrid.ipynb` | Crop-specific evaluation of the same hybrid architecture |

## Important verification finding

The current GitHub copy of at least `NB1_Wheat_Hybrid.ipynb` begins with `execution_count: null` and empty outputs in the inspected cells. The notebook source also contains a Kaggle credential assignment. Therefore the repository copy itself should **not** be treated as proof that the saved result was produced by this exact GitHub file.

The aggregate Wheat result currently recorded in `paper/results.csv` is retained as a project result because it was present in the earlier consolidated experiment record, but the provenance of that exact output should be reconciled against the original executed notebook/log before final submission.

This distinction is intentional: the paper must not imply that an unexecuted or stripped notebook generated a result merely because a matching number appears in a CSV.

## Security finding

The inspected notebook contains a hard-coded Kaggle API credential. It must not remain in a public repository. The credential should be revoked/rotated and the notebook should be sanitised to use an environment variable or a local ignored credential file. No credential value is reproduced in this audit.

## Reporting rule

The manuscript should cite only metrics that can be traced to one of the following:

1. a saved output inside the executed source notebook;
2. an exported metrics CSV/report generated by that experiment; or
3. a previously preserved project result whose provenance can be demonstrated from the repository history/logs.

If a notebook has no saved execution output and no corresponding exported evidence, it should remain in the main/archive branch rather than being presented as experimental evidence in the paper branch.

## Figure extraction rule

Training curves, confusion matrices, ROC/PR curves, class-distribution plots, and augmentation visualisations must be copied into `paper_figures/` only after checking the saved outputs. They must not be regenerated by executing notebooks and must not be reconstructed from aggregate metrics.
