# Results — Augmentation Sensitivity Study

This folder contains the saved notebooks associated with the augmentation experiments. The paper reports the controlled policy comparison as a separate results section rather than mixing it into preprocessing.

Recorded policies in the consolidated result table:

- Hybrid-NoAug
- Hybrid-CropColour
- Hybrid-LightAug
- Hybrid-LightAug-v2
- Hybrid-FullAug

The notebook filenames are retained from the project record because the experimental outputs, rather than filename similarity, determine the reported result mapping. The potato augmentation example is intentionally excluded because it is a reference paper example, not a PlantDiseaseNet-Hybrid experiment.
