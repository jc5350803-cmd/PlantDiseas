# Results — Architectural Ablation

This folder contains the controlled architecture comparisons used to analyse the proposed Inception(Add) + SkipConnection(Concat) design.

- `NB4_Combined_StandardInception.ipynb`
- `NB5_Combined_ResNet.ipynb`
- `NB6_Combined_InceptionAdd.ipynb`
- `NB7_Combined_SkipConcat.ipynb`

The complete hybrid is the fifth configuration in the paper comparison and is represented by the main combined experiment record. All configurations use the same 24-class benchmark and LightAug condition for the reported ablation table.
