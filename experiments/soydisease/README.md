# Results — SoyDisease Evaluation

This folder contains the six saved SoyDisease notebooks retained from the project record. They belong to the additional Indian soybean evaluation in the paper and are not SoyCultivar200 experiments.

The source dataset is the published Indian soyabean dataset of Kotwal, Kashyap and Pathan (2024), Mendeley Data DOI 10.17632/bshkvgbzpt.1.

The original dataset contains 3363 images. The executed project configuration uses a processed 1176-image subset with six classes. Because Root Images contains only 10 samples, the paper treats the five-fold cross-validation result (99.57% ± 0.85% mean accuracy) as the principal soybean estimate and does not use the two 100% single-split runs as headline evidence.
