# Dataset sources used in the manuscript

The manuscript should cite the original/publication-level source for each dataset rather than citing a Kaggle page alone.

## PlantVillage

Primary scholarly source: Hughes, D. P., and Salathé, M. (2015), *An open access repository of images on plant health to enable the development of mobile disease diagnostics through machine learning and crowdsourcing*. The dataset is also documented through the PlantVillage research/code ecosystem. The present study uses the PlantVillage classes selected in the executed experiment rather than claiming use of all 38 classes.

Scholarly source: https://arxiv.org/abs/1511.08060

Related peer-reviewed use/citation: Mohanty, S. P., Hughes, D. P., and Salathé, M. (2016), *Using deep learning for image-based plant disease detection*, Frontiers in Plant Science, 7, 1419. DOI: 10.3389/fpls.2016.01419.

## Wheat Disease Detection Dataset

The three-class wheat experiment uses Brown Rust, Healthy, and Yellow Rust. A peer-reviewed study explicitly describes the Wheat Disease Detection Dataset, identifies Safarijalal et al. (2022) as its origin, and provides the public Kaggle dataset reference. The dataset contains 1,128 Brown Rust, 1,395 Healthy, and 1,156 Yellow Rust images in that published description.

Peer-reviewed source documenting the dataset: *A deep learning based approach for automated plant disease classification using vision transformer* (2022), available through PubMed Central.

Dataset source: https://www.kaggle.com/datasets/sinadunk23/behzad-safari-jalal

## Cotton Plant Disease Dataset

The cotton experiment uses Aphids, Army Worm, Bacterial Blight, Healthy, Powdery Mildew, and Target Spot. A peer-reviewed Frontiers in Plant Science article documents this dataset as the Cotton Plant Disease database by Dhamodharan (2023), and the dataset page describes the same six classes.

Peer-reviewed source: *Advanced deep transfer learning techniques for efficient detection of cotton plant diseases*, Frontiers in Plant Science (2024).

Dataset source: https://www.kaggle.com/datasets/dhamur/cotton-plant-disease

## Soybean Disease Dataset

The SoyDisease study uses the six-class India soyabean dataset: Healthy, Vein Necrosis, Dry Leaf, Septoria Brown Spot, Root Images, and Bacterial Leaf Blight. The original Data in Brief publication by Kotwal, Kashyap, and Pathan (2024) is the appropriate scholarly dataset citation. It reports the same class structure and class counts used by the executed notebook subset: 288 Healthy, 138 Vein Necrosis, 230 Dry Leaf, 284 Septoria Brown Spot, 10 Root Images, and 226 Bacterial Leaf Blight, totaling 1,176 images in the processed subset.

Scholarly source: Kotwal, J., Kashyap, R., and Pathan, M. S. (2024), *An India soyabean dataset for identification and classification of diseases using computer-vision algorithms*, Data in Brief, 53, 110216. DOI: 10.1016/j.dib.2024.110216.

Original dataset repository: https://data.mendeley.com/datasets/bshkvgbzpt/1

## Augmentation reporting reference

Mhala, P., Bilandani, A., and Sharma, S. (2025), *Enhancing crop productivity with fine-tuned deep convolution neural network for Potato leaf disease detection*, Expert Systems with Applications, 267, 126066. DOI: 10.1016/j.eswa.2024.126066.

This paper is used only as a methodological/reporting reference for presenting a dedicated augmentation study. Its potato results are not used as results for PlantDiseaseNet-Hybrid.
