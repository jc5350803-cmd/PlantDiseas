# 04 — Augmentation Study

Augmentation is a dedicated experimental section, not a subsection hidden inside preprocessing.

## Included scope
Use only the executed augmentation notebooks that can be traced to the paper. The Potato augmentation demonstration is excluded; it is a presentation reference based on Mhala et al. (2025).

## Required reporting sequence
1. Baseline class distribution.
2. Exact augmentation operations used.
3. Per-class augmentation policy and resulting counts.
4. Baseline versus augmented training/validation curves.
5. Baseline versus augmented test metrics.
6. Per-class performance changes.
7. Interpretation of whether augmentation improves minority-class coverage and generalization.

The current evidence audit has not yet assigned numerical values to candidate augmentation notebooks because their complete result artifacts have not all been independently verified. Do not fill this section with assumed values.
